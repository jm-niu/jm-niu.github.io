第十八章：异步 IO

难度：高级 预计学习时间：1-2 周 前置知识：函数、并发基础

当程序需要同时等待多个网络请求、数据库查询或文件读写时，传统的"一个一个等"会非常慢。asyncio 是 Python 内置的异步 IO 框架：它在单线程内通过"协作式调度"实现并发——当一个协程在等待 IO 时，事件循环会立刻切换到另一个协程去干活。这种方式既避免了多线程的锁复杂度，又大幅提升了 IO 密集型任务的吞吐。

async / await 协程

用 async def 定义的函数称为协程函数，调用它不会立即执行，而是返回一个协程对象。在协程内部，用 await 挂起当前协程、把控制权交还事件循环，直到被等待的对象准备就绪。

Python 
import asyncio
import time

# async def 定义协程函数
async def say_after(delay, message):
    await asyncio.sleep(delay)  # 挂起，期间事件循环可运行别的协程
    print(message)

# 直接调用只返回协程对象，并不执行
coro = say_after(1, "hello")
print(type(coro))  # <class 'coroutine'>

# 必须放进事件循环里运行
async def main():
    await say_after(1, "世界")
    await say_after(2, "你好")

start = time.time()
asyncio.run(main())  # 入口：创建事件循环并运行 main
print(f"耗时约 {time.time() - start:.1f} 秒")  # 顺序执行约 3 秒
前端 JS/TS 类比：async/await（几乎一致！）

Python 的 async def / await 与 JavaScript 的写法几乎完全相同。两者都用 async 标记函数、用 await 暂停等待；区别仅在于 Python 用 asyncio.run() 启动事件循环，而 JS 的 async 函数由引擎自动调度。心智模型可以完全通用。

JavaScript 
// JS 中的 async/await —— 与 Python 同构
function sleep(ms) {
  return new Promise((resolve) => setTimeout(resolve, ms));
}

async function sayAfter(delay, message) {
  await sleep(delay * 1000); // 挂起，释放主线程
  console.log(message);
}

async function main() {
  await sayAfter(1, "世界");
  await sayAfter(2, "你好");
}

main(); // JS 引擎自动驱动事件循环

事件循环

事件循环（event loop）是 asyncio 的"发动机"：它不断检查哪些协程可以继续执行，并在 IO 就绪时唤醒它们。asyncio.run() 会创建一个新事件循环、运行传入的协程、结束后自动关闭循环。日常开发中你几乎不需要手动管理它。

Python 
import asyncio

async def task(name):
    print(f"{name} 开始")
    await asyncio.sleep(1)
    print(f"{name} 结束")

# 方式一（推荐）：asyncio.run 自动管理循环生命周期
async def main():
    await task("A")

asyncio.run(main())

# 方式二：手动获取并驱动循环（了解即可）
loop = asyncio.new_event_loop()
asyncio.set_event_loop(loop)
try:
    loop.run_until_complete(task("B"))
finally:
    loop.close()

# 在一个循环里顺序运行多个协程
async def run_all():
    await asyncio.gather(task("X"), task("Y"))
asyncio.run(run_all())
提示

在 Jupyter Notebook、Web 框架（如 FastAPI）等环境中，事件循环可能已经存在，此时不应再调用 asyncio.run()，否则会报"事件循环已关闭"等错误。直接用 await 即可。

协程与任务并发

单纯用 await 是顺序执行的。要真正并发，需要把协程包装成任务（Task）：asyncio.create_task() 会立即把协程排入事件循环并"同时"开始；asyncio.gather() 则可一次性等待多个协程全部完成。

Python 
import asyncio
import time

async def job(n):
    await asyncio.sleep(1)  # 模拟 IO 等待
    return f"任务{n}完成"

async def main():
    # create_task：三个任务"同时"启动，总耗时≈1秒而非3秒
    t1 = asyncio.create_task(job(1))
    t2 = asyncio.create_task(job(2))
    t3 = asyncio.create_task(job(3))

    # 等待各自结果
    r1 = await t1
    r2 = await t2
    r3 = await t3
    print(r1, r2, r3)

    # gather：更简洁地并发并收集结果（保持顺序）
    results = await asyncio.gather(job(4), job(5), job(6))
    print(results)  # ['任务4完成', '任务5完成', '任务6完成']

start = time.time()
asyncio.run(main())
print(f"总耗时约 {time.time() - start:.1f} 秒")  # 约 1 秒
前端 JS/TS 类比：Promise.all

asyncio.gather() 等价于 JS 的 Promise.all()：都用于并发启动多个异步任务并等待它们全部完成，且结果按输入顺序返回。Python 的 create_task 则类似 Promise 构造函数——把异步操作"登记"进调度器。

JavaScript 
// JS: Promise.all 并发等待多个异步任务
function job(n) {
  return new Promise((resolve) =>
    setTimeout(() => resolve(`任务${n}完成`), 1000)
  );
}

async function main() {
  const results = await Promise.all([job(1), job(2), job(3)]);
  console.log(results); // ["任务1完成", "任务2完成", "任务3完成"]
}
main();

aiohttp — 异步 HTTP 请求

标准库 requests 是阻塞式的，在 asyncio 中应使用异步客户端 aiohttp。它的 ClientSession 配合 await 能在等待网络响应时让出控制权，从而并发抓取多个网页。安装：pip install aiohttp。

Python 
# 先执行: pip install aiohttp
import asyncio
import aiohttp

async def fetch(session, url):
    async with session.get(url, timeout=aiohttp.ClientTimeout(total=5)) as resp:
        print(f"{url} -> {resp.status}")
        return await resp.text()

async def main():
    urls = [
        "https://httpbin.org/get",
        "https://example.com",
        "https://python.org",
    ]
    # ClientSession 复用连接，推荐用 async with 管理
    async with aiohttp.ClientSession() as session:
        # gather 并发发起所有请求，总耗时≈最慢那一个
        pages = await asyncio.gather(*(fetch(session, u) for u in urls))
        print(f"共抓取 {len(pages)} 个页面")

asyncio.run(main())
注意

不要在协程里混用阻塞的 requests.get()，它会卡住整个事件循环，使并发化为乌有。异步代码里务必使用 aiohttp、asyncpg、aiomysql 等原生支持 await 的库。

前端 JS/TS 类比：fetch + await

aiohttp.ClientSession.get() + await 与浏览器里的 fetch() + await 概念一致：都是异步发起 HTTP 请求、在响应就绪前让出控制权。两者都是"非阻塞 IO"思维的直接体现。

JavaScript 
// JS 浏览器/Node: fetch + await 异步请求
async function fetchAll(urls) {
  const promises = urls.map((u) =>
    fetch(u).then((r) => {
      console.log(u, "->", r.status);
      return r.text();
    })
  );
  const pages = await Promise.all(promises); // 并发抓取
  console.log(`共抓取 ${pages.length} 个页面`);
}
fetchAll(["https://example.com", "https://python.org"]);

练习建议 动手实践

  1. 并发抓取多个 URL — 用 aiohttp + asyncio.gather 同时抓取 5 个不同网页，统计每个页面的字节数并总耗时。
  2. gather 示例 — 写 3 个参数不同的协程任务（如模拟下载、转码、上传），用 gather 并发运行，观察总耗时是否约等于最慢单项。
  3. 异步计时器 — 用 asyncio.sleep 实现一个每秒打印一次当前时间的异步协程，运行 10 秒后自动退出。
  4. aiohttp 实战 — 用 aiohttp 向 https://httpbin.org/post 并发发送多个带不同 JSON 体的 POST 请求，并打印各自返回的 json 字段。
