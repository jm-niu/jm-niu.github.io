第十七章：第三方库与虚拟环境

难度：高级 预计学习时间：1 周 前置知识：模块与包管理、虚拟环境基础

Python 之所以强大，很大程度上得益于其庞大而活跃的第三方库生态。但直接使用系统 Python 安装全局库，容易造成不同项目之间的依赖冲突。本章我们学习如何用虚拟环境隔离项目依赖，并实战五个最常用的第三方库：requests、Pillow、chardet 与 psutil。

虚拟环境详解

虚拟环境（virtual environment）是一个独立的 Python 运行目录，拥有自己的 site-packages 和 Python 解释器副本。它能让不同项目使用互不干扰的依赖版本。Python 3.3+ 内置了 venv 模块，无需额外安装。

Bash 
# 1. 创建虚拟环境（会在当前目录生成 venv 文件夹）
python -m venv venv

# 2. 激活环境
# macOS / Linux
source venv/bin/activate
# Windows (PowerShell)
venv\Scripts\Activate.ps1

# 激活后，命令行前缀会出现 (venv)
# 此时 pip install 的包只装在当前环境

# 3. 导出依赖列表
pip freeze > requirements.txt

# 4. 在另一台机器/新环境中一键安装
pip install -r requirements.txt

# 5. 退出虚拟环境
deactivate
提示

记得把 venv/ 目录加入 .gitignore，不要把虚拟环境提交到版本库。requirements.txt 则应随项目一起保存，方便他人复现环境。

如果你同时维护多个项目，频繁 source .../activate 会比较繁琐。社区有 virtualenvwrapper 这样的工具，它把每个虚拟环境集中管理，并提供 mkvirtualenv、workon、deactivate 等更简洁的命令：

Bash 
# 安装 virtualenvwrapper（pip install 即可）
pip install virtualenvwrapper

# 创建并进入环境
mkvirtualenv myproject

# 在任意目录一键切换环境
workon myproject

# 退出
deactivate

# 删除环境
rmvirtualenv myproject
前端 JS/TS 类比：环境与版本管理

Python 的 venv + requirements.txt 相当于 JS 世界的 npm + package.json：前者管理隔离的包目录，后者锁定依赖清单。而 virtualenvwrapper 则类似 nvm（Node Version Manager）——它帮你集中管理多个互相独立的运行环境，并快速切换。

JavaScript 
// JS 中对应的工作流：用 package.json 锁定依赖
// npm init -y 生成 package.json
// npm install lodash  写入 dependencies

// 全局安装 nvm 后可切换 Node 版本，类似 virtualenvwrapper
// nvm use 18
// nvm use 20

// Python 的 requirements.txt  ≈  package-lock.json
// 两者都用于"锁定环境、可复现构建"
const deps = require("./package.json").dependencies;
console.log(deps); // { lodash: "^4.17.21" }

requests — 优雅的 HTTP 客户端

requests 是 Python 中最流行的 HTTP 库，用人类可读的方式发起网络请求。使用前需先安装：pip install requests。

Python 
# 先执行: pip install requests
import requests

# GET 请求，通过 params 传递查询参数（自动 URL 编码）
resp = requests.get(
    "https://httpbin.org/get",
    params={"q": "python", "page": 1},
    timeout=5,  # 超时时间（秒），防止无限等待
)

# 响应状态码与内容
print(resp.status_code)        # 200
print(resp.url)                # 实际请求的完整 URL
print(resp.text)               # 响应体原文（字符串）

# 如果返回的是 JSON，直接用 .json() 解析为字典
data = resp.json()
print(data["args"])            # {'q': 'python', 'page': '1'}

# POST 请求，用 json= 自动序列化并设置 Content-Type
resp = requests.post(
    "https://httpbin.org/post",
    json={"username": "alice", "age": 25},
    timeout=5,
)
print(resp.json()["json"])     # {'username': 'alice', 'age': 25}

# 异常处理：网络问题、超时都会抛出 RequestException
from requests.exceptions import RequestException
try:
    r = requests.get("https://example.com", timeout=3)
    r.raise_for_status()  # 状态码非 2xx 时主动抛异常
except RequestException as e:
    print("请求失败:", e)
前端 JS/TS 类比：fetch 与 axios

requests.get(...) 同步地返回响应对象，对应 JS 中的 await fetch(...) 或 await axios.get(...)。区别在于：Python 这里是阻塞式调用（线程会等待），而 JS 的 fetch 返回 Promise、需要 await。它们的理念一致——把 HTTP 请求变成简单的函数调用。

JavaScript 
// JS: 用 axios 发起 GET（概念几乎等同 requests）
import axios from "axios";

const resp = await axios.get("https://httpbin.org/get", {
  params: { q: "python", page: 1 },
  timeout: 5000,
});
console.log(resp.status);   // 200
console.log(resp.data);     // 直接就是解析好的对象

// 原生 fetch 版本
const r = await fetch("https://httpbin.org/get?q=python&page=1");
const data = await r.json();

Pillow — 图像处理利器

Pillow（PIL 的现代分支）是 Python 处理图片的标准库。安装：pip install Pillow。

Python 
# 先执行: pip install Pillow
from PIL import Image

# 打开图片
img = Image.open("photo.jpg")
print(img.size)      # (宽, 高)，如 (1920, 1080)
print(img.mode)      # 'RGB' / 'RGBA' / 'L' 等

# 缩放：thumbnail 会就地修改并保持比例
img.thumbnail((300, 300))
img.save("photo_thumb.jpg")

# 裁剪：传入 (左, 上, 右, 下) 像素坐标
box = (100, 100, 400, 400)
cropped = img.crop(box)
cropped.save("cropped.png")

# 旋转与格式转换
rotated = img.rotate(45)
rotated.save("rotated.webp")  # 也可直接改保存格式

# 新建空白画布并合成
canvas = Image.new("RGB", (500, 500), (255, 255, 255))
canvas.paste(cropped, (50, 50))
canvas.save("composite.jpg")
注意

img.thumbnail() 会直接修改原对象且不返回新对象；而 img.resize() 会返回一个新的 Image。处理完后务必调用 .save()，否则修改只存在于内存中。

chardet — 自动检测文本编码

当你拿到一个未知来源的文本文件，不知道它是 UTF-8、GBK 还是其他编码时，chardet 可以帮你猜。安装：pip install chardet。

Python 
# 先执行: pip install chardet
import chardet

# 检测字节串的编码（注意要读二进制，不要预先解码）
with open("unknown.txt", "rb") as f:
    raw = f.read()

result = chardet.detect(raw)
print(result)
# 例如: {'encoding': 'utf-8', 'confidence': 0.99, 'language': ''}

# 用检测到的编码正确读取文本
encoding = result["encoding"]
with open("unknown.txt", encoding=encoding) as f:
    text = f.read()
print(text)
提示

detect() 返回的 confidence 是置信度（0~1）。对于大文件，可先读取一小段（如前 1 万字节）来检测，既快又足够准确。

psutil — 跨平台系统监控

psutil 能获取 CPU、内存、磁盘、网络以及进程信息，是写运维/监控脚本的好帮手。安装：pip install psutil。

Python 
# 先执行: pip install psutil
import psutil

# CPU 信息
print(psutil.cpu_count())              # 逻辑核心数
print(psutil.cpu_percent(interval=1))  # 1秒内的平均使用率(%)

# 内存信息
mem = psutil.virtual_memory()
print(mem.total, mem.available, mem.percent)  # 总/可用/使用率%

# 磁盘信息
disk = psutil.disk_usage("/")
print(f"磁盘使用率: {disk.percent}%")

# 遍历进程
for proc in psutil.process_iter(["pid", "name", "cpu_percent"]):
    print(proc.info)
    # 例如: {'pid': 1234, 'name': 'Python', 'cpu_percent': 0.0}

# 找到名为 "chrome" 的进程并读取其内存占用
for p in psutil.process_iter(["name", "memory_info"]):
    if p.info["name"] == "chrome":
        print(p.info["memory_info"].rss)  # 常驻内存字节数
        break

练习建议 动手实践

  1. 网页标题抓取器 — 用 requests 抓取一个网页的 HTML，用字符串方法或正则提取 <title>...</title> 中的标题并打印。
  2. 批量缩略图生成 — 遍历某个文件夹下的所有 .jpg，用 Pillow 统一缩放为 200×200 的缩略图，保存到 thumbs/ 目录。
  3. 系统监控脚本 — 用 psutil 写一个脚本，每隔 5 秒打印一次 CPU 使用率和可用内存，持续 1 分钟。
  4. 编码检测工具 — 用 chardet 批量检测一个目录下所有 .txt 文件的编码，输出「文件名 → 编码 (置信度)」列表。
