第十五章：常用内置模块

难度：高级 预计学习时间：1-2 周 前置知识：函数、模块基础

装好 Python 就自带了一整套"标准库"，无需额外安装即可使用。本章挑选日常开发最高频的几个内置模块：处理时间的 datetime、增强容器 collections、迭代利器 itertools、编码与摘要工具、资源管理 contextlib，以及网络请求 urllib。

datetime：时间与日期

datetime 模块提供 datetime、date、time、timedelta 等类型。用 strftime 把时间格式化为字符串，用 strptime 反向解析。涉及时区时使用 timezone 或第三方 pytz。

Python 
from datetime import datetime, date, timedelta, timezone

# 当前时间
now = datetime.now()
print(now)                     # 2026-06-23 10:22:05.123456
print(now.strftime("%Y-%m-%d %H:%M:%S"))  # 2026-06-23 10:22:05

# 解析字符串
dt = datetime.strptime("2026-06-23", "%Y-%m-%d")
print(dt.date())               # 2026-06-23

# 日期加减
tomorrow = date.today() + timedelta(days=1)
last_week = now - timedelta(weeks=1)
print(tomorrow, last_week)

# 时区（UTC+8 示例）
bj = datetime.now(timezone(timedelta(hours=8)))
print(bj.isoformat())
前端 JS/TS 类比：日期处理

JS 内置的 Date 对象功能有限且 API 反直觉；生态里常用 dayjs / moment。Python 的 datetime 更像 dayjs：链式、可读、支持加减。

JavaScript 
import dayjs from "dayjs";

const now = dayjs();
console.log(now.format("YYYY-MM-DD HH:mm:ss"));
console.log(now.add(1, "day").format("YYYY-MM-DD"));  // 明天
console.log(now.subtract(1, "week").format("YYYY-MM-DD"));

collections：增强容器

这些容器在标准 dict/list/tuple 之上做了增强，能写出更简洁、更高效的代码。

Python 
from collections import Counter, defaultdict, deque, namedtuple, OrderedDict

# Counter：计数
colors = ["red", "blue", "red", "green", "blue", "red"]
print(Counter(colors))                 # Counter({'red': 3, 'blue': 2, 'green': 1})
print(Counter(colors).most_common(2))  # [('red', 3), ('blue', 2)]

# defaultdict：访问缺失键时自动给默认值
dd = defaultdict(list)
dd["a"].append(1)         # 不用先判断 key 是否存在
print(dd)                 # defaultdict(<class 'list'>, {'a': [1]})

# deque：双端队列，两端插入/弹出都是 O(1)
dq = deque([1, 2, 3])
dq.appendleft(0)
dq.append(4)
print(dq)                 # deque([0, 1, 2, 3, 4])

# namedtuple：可读的元组
Point = namedtuple("Point", ["x", "y"])
p = Point(3, 5)
print(p.x, p.y)           # 3 5

# OrderedDict：保持插入顺序（Python3.7+ 普通 dict 也已保序）
od = OrderedDict()
od["b"] = 2
od["a"] = 1
print(list(od.keys()))    # ['b', 'a']
前端 JS/TS 类比：容器

JS 用 Map 代替 defaultdict（Map.get 可配合 ?? 兜底），用普通数组 + unshift/push 近似 deque，用对象字面量近似 namedtuple。

JavaScript 
// 计数 = Array + reduce
const colors = ["red", "blue", "red"];
const counter = colors.reduce((m, c) => {
  m[c] = (m[c] ?? 0) + 1;
  return m;
}, {});
console.log(counter);   // { red: 2, blue: 1 }

// 双端队列近似
const dq = [1, 2, 3];
dq.unshift(0);
dq.push(4);

itertools：迭代工具

itertools 提供一系列"惰性"迭代器，适合处理无限序列或组合问题，内存占用极低。

Python 
import itertools

# count：无限计数（需自行截断）
for i in itertools.islice(itertools.count(10, 2), 5):
    print(i)            # 10 12 14 16 18

# cycle：无限循环
print(list(itertools.islice(itertools.cycle("AB"), 5)))  # ['A','B','A','B','A']

# repeat：重复
print(list(itertools.repeat("x", 3)))                    # ['x','x','x']

# chain：拼接多个迭代器
print(list(itertools.chain([1, 2], [3, 4])))             # [1,2,3,4]

# groupby：按 key 分组（需先排序）
data = sorted(["apple", "apricot", "banana", "blue"], key=lambda s: s[0])
for k, g in itertools.groupby(data, key=lambda s: s[0]):
    print(k, list(g))   # a ['apple','apricot']  b ['banana','blue']

# permutations：全排列
print(list(itertools.permutations("ABC", 2)))  # 所有 2 元排列
前端 JS/TS 类比：惰性迭代

JS 没有内置 itertools，但其生成器函数（function* + yield）同样能产出惰性的无限序列，思想与 itertools 一致。

JavaScript 
// 等价的惰性计数生成器
function* count(start = 0, step = 1) {
  let i = start;
  while (true) {
    yield i;
    i += step;
  }
}
const gen = count(10, 2);
console.log([gen.next().value, gen.next().value]);  // 10, 12

编码与摘要

base64 用于二进制数据编成可打印文本；hashlib 计算 md5 / sha256 等摘要；hmac 在摘要基础上加入密钥，用于校验完整性。

Python 
import base64, hashlib, hmac

# base64 编解码（处理 bytes）
raw = b"hello python"
enc = base64.b64encode(raw).decode()
print(enc)                          # aGVsbG8gcHl0aG9u
print(base64.b64decode(enc))        # b'hello python'

# hashlib 摘要
sha = hashlib.sha256(b"hello").hexdigest()
print(sha[:16])                     # 2cf24dba5fb0a30e...（64 位十六进制）

md5 = hashlib.md5(b"hello").hexdigest()
print(md5)                          # 5d41402abc4b2a76b9719d911017c592

# hmac：带密钥的摘要
key = b"secret"
sig = hmac.new(key, b"hello", hashlib.sha256).hexdigest()
print(sig[:16])
前端 JS/TS 类比：编码与加密

浏览器里 btoa/atob 对应 base64；更强的摘要/签名走 Web Crypto API 的 crypto.subtle。两者都是标准算法，跨语言结果一致。

JavaScript 
// base64
const enc = btoa("hello python");
console.log(enc);            // aGVsbG8gcHl0aG9u
console.log(atob(enc));      // hello python

// 异步的 SHA-256（Web Crypto）
const buf = await crypto.subtle.digest("SHA-256",
  new TextEncoder().encode("hello"));
console.log([...new Uint8Array(buf)].map(b =>
  b.toString(16).padStart(2, "0")).join(""));

contextlib：简化 with

用 @contextmanager 装饰器，可以把一个普通生成器函数变成上下文管理器，省去手写 __enter__/__exit__；closing 则确保对象退出时调用 .close()。

Python 
from contextlib import contextmanager, closing

# 自定义上下文管理器
@contextmanager
def tag(name):
    print(f"<{name}>")
    yield
    print(f"</{name}>")

with tag("section"):
    print("  内容在这里")

# closing：保证 close 被调用
from urllib.request import urlopen
with closing(urlopen("https://example.com")) as page:
    print(page.status)
前端 JS/TS 类比：资源清理

TS 5.2+ 的 using 声明（显式资源管理）与 Python 的 with 目标一致：离开作用域时自动释放资源（文件、连接等）。

JavaScript 
// TS 5.2+：离开作用域自动调用 [Symbol.dispose]()
function openFile(path) {
  return {
    read() { /* ... */ },
    [Symbol.dispose]() { console.log("close"); }
  };
}
using f = openFile("a.txt");
f.read();   // 作用域结束自动 close

urllib：网络请求

urllib.request 是标准库自带的 HTTP 客户端，能抓取网页。不过实际项目更推荐第三方 requests 库，API 更友好。

Python 
from urllib.request import urlopen, Request

# 抓取网页（标准库方式）
req = Request("https://example.com", headers={"User-Agent": "Mozilla/5.0"})
with urlopen(req, timeout=10) as resp:
    html = resp.read().decode("utf-8")
    print(len(html), "字符")

# 推荐：第三方 requests（需 pip install requests）
# import requests
# r = requests.get("https://example.com")
# print(r.text)
提示

标准库 urllib 写起来较啰嗦且对 HTTPS、Cookie、重定向的处理不够顺手。日常开发强烈建议安装 requests：一行 requests.get(url) 即可。

练习建议 动手实践

  1. 词频统计 — 读取一篇英文短文，用 Counter 统计每个单词出现次数，并打印出现最多的前 10 个词。
  2. 日期计算 — 计算"今天"距离你设定的某个目标日期（如 2027-01-01）还有多少天，并格式化输出剩余天数。
  3. 文件摘要 — 写一个函数，以二进制方式读取任意文件，返回它的 SHA-256 十六进制摘要字符串。
  4. 排列组合 — 用 itertools.permutations 或 combinations 求出字符 "ABCD" 中任选 3 个的所有组合。
