第十四章：正则表达式

难度：高级 预计学习时间：1 周 前置知识：字符串操作基础

正则表达式（Regular Expression）是一种用于描述字符串模式的语言，常被用来做复杂的查找、匹配、提取与替换。Python 通过内置的 re 模块提供支持。掌握它，你就能用极少的代码处理大量文本任务。

re 基础

re 模块最常用的四个函数是 match、search、findall 和 split。注意：正则中的反斜杠很多，建议使用原始字符串 r"..." 来书写，避免被 Python 自身的字符串转义干扰。

  • re.match(pattern, s)：从字符串开头匹配，失败返回 None。
  • re.search(pattern, s)：扫描整个字符串，返回第一个匹配。
  • re.findall(pattern, s)：返回所有非重叠匹配的列表。
  • re.split(pattern, s)：按模式切分字符串。
Python 
import re

text = "订单号 2026ABC 金额 998 元，订单号 2027XYZ 金额 520 元"

# re.match 只从开头匹配
m = re.match(r"\d+", text)
print(m)  # None，因为 text 不是以数字开头

# re.search 扫描整个字符串，返回第一个匹配
s = re.search(r"\d+", text)
print(s.group())  # '2026'

# re.findall 返回所有匹配组成的列表
nums = re.findall(r"\d+", text)
print(nums)  # ['2026', '998', '2027', '520']

# re.split 按模式切分
parts = re.split(r"\s+", "用  多个  空格  分割")
print(parts)  # ['用', '多个', '空格', '分割']

# 原始字符串 r"..." 防止转义
print(r"\n")  # 两个字符：反斜杠和 n（不会变成换行）
提示

如果同一个正则要在多处重复使用，先用 pat = re.compile(r"模式") 编译一次，再调用 pat.search() 等方法，效率更高。

前端 JS/TS 类比：正则表达式

JavaScript 同样内置正则支持。JS 用 /pattern/flags 字面量或 new RegExp() 创建正则对象；Python 则用 re.compile() 或直接在函数里传入字符串。两者的方法命名略有差异，但思想完全一致。

JavaScript 
const text = "订单号 2026ABC 金额 998 元";

// 等价 re.search：扫描第一个匹配
const s = text.match(/\d+/);
console.log(s ? s[0] : null);  // "2026"

// 等价 re.findall：全局匹配用 g 标志
const nums = text.match(/\d+/g);
console.log(nums);  // ["2026", "998"]

// 编译正则
const pat = new RegExp(/\d+/g);
console.log(pat.test(text));   // true

匹配规则

正则的强大来自它的一套"元字符"。下面是最常用的几个：

  • \d 数字、\w 字母数字下划线、\s 空白字符。
  • . 匹配除换行外的任意字符。
  • * 重复 0 次或多次、+ 1 次或多次、? 0 或 1 次。
  • {n,m} 重复 n 到 m 次。
  • ^ 行首、$ 行尾。
  • [...] 字符集合，如 [a-z0-9]。
注意

正则默认是贪婪的：.* 会尽可能多吃字符。在 *、+ 后加 ? 变成非贪婪（如 .*?），让它匹配到第一个满足的位置就停。提取内容时经常需要非贪婪。

Python 
import re

html = "<title>第一章</title><title>第二章</title>"

# 贪婪：会一直吃到最后一个 </title>
print(re.findall(r"<title>.*</title>", html))
# ['<title>第一章</title><title>第二章</title>']

# 非贪婪：每个 <title> 单独匹配
print(re.findall(r"<title>.*?</title>", html))
# ['<title>第一章</title>', '<title>第二章</title>']

# 字符集合与次数
print(re.findall(r"[a-z]{3}", "abc def ghij"))   # ['abc', 'def', 'ghi']
print(re.search(r"^\d+$", "12345").group())        # '12345'（整串都是数字）
print(re.findall(r"\w+", "hello_world 2026"))      # ['hello_world', '2026']

分组与替换

用括号 () 可以把正则的一部分"分组"。匹配后用 group(1)、groups() 取出各组内容；re.sub() 则可以基于分组做替换。命名分组 (?P<name>...) 让代码更易读。

Python 
import re

# 普通分组：group(0) 是整串，group(1) 是第一组
m = re.search(r"(\d{4})-(\d{2})-(\d{2})", "日期 2026-06-23")
print(m.group(0))   # '2026-06-23'
print(m.group(1))   # '2026'
print(m.groups())   # ('2026', '06', '23')

# 命名分组：用 ?P<name> 给分组起名字
m2 = re.search(r"(?P<year>\d{4})-(?P<month>\d{2})-(?P<day>\d{2})", "2026-06-23")
print(m2.group("year"))   # '2026'
print(m2.groupdict())     # {'year': '2026', 'month': '06', 'day': '23'}

# 替换：把日期格式从 年-月-日 改成 月/日/年
text = "今天是 2026-06-23，截止 2026-07-01"
new = re.sub(r"(\d{4})-(\d{2})-(\d{2})", r"\2/\3/\1", text)
print(new)  # '今天是 06/23/2026，截止 07/01/2026'
前端 JS/TS 类比：捕获组

JS 的正则也能用括号分组，match() 返回的数组下标 1 起就是各组，用法和 Python 的 group(1) 对应；现代 JS 还提供 match.groups 直接拿到命名组对象，等价于 Python 的 groupdict()。

JavaScript 
const text = "日期 2026-06-23";

// 普通捕获组
const m = text.match(/(\d{4})-(\d{2})-(\d{2})/);
console.log(m[1]);   // "2026"

// 命名组 (ES2018+)
const m2 = text.match(/(?<year>\d{4})-(?<month>\d{2})-(?<day>\d{2})/);
console.log(m2.groups);  // { year: "2026", month: "06", day: "23" }

// 替换
const newText = text.replace(/(\d{4})-(\d{2})-(\d{2})/g, "$2/$3/$1");

实战示例

下面把前面的知识组合起来，解决三个日常问题：提取邮箱、验证手机号、提取 URL。

Python 
import re

# 示例一：提取文本中所有邮箱
text = "联系 alice@example.com 或 bob_99@mail.cn 获取支持"
emails = re.findall(r"[\w.+-]+@[\w-]+\.[\w.-]+", text)
print(emails)  # ['alice@example.com', 'bob_99@mail.cn']

# 示例二：验证中国大陆手机号（1 开头，第二位 3-9，共 11 位）
phones = ["13812345678", "12345678901", "19900001111"]
for p in phones:
    if re.fullmatch(r"1[3-9]\d{9}", p):
        print(f"{p} 是合法手机号")
    else:
        print(f"{p} 不合法")

# 示例三：提取 URL（http/https）
html = '访问 <a href="https://python.org">官网</a> 和 http://docs.x.org 吧'
urls = re.findall(r"https?://[\w./?=&#-]+", html)
print(urls)  # ['https://python.org', 'http://docs.x.org']
提示

验证"整串是否完全匹配"时优先用 re.fullmatch()，它等价于在模式两端自动加上 ^ 和 $，避免"部分匹配"造成的误判。

练习建议 动手实践

  1. 提取所有邮箱 — 给定一段包含多个邮箱、电话和网址的长文本，用 re.findall 把所有邮箱提取成一个列表并打印。
  2. 验证手机号 — 写一个函数 is_valid_phone(s)，用正则判断字符串是否为合法的中国大陆手机号，返回布尔值。
  3. 替换敏感词 — 准备一个敏感词列表，用 re.sub 将文本中出现的所有敏感词替换为 ***。
  4. 解析一行日志 — 形如 [2026-06-23 10:22:05] INFO user=alice action=login 的日志，用命名分组提取出时间、级别、用户名和操作。
