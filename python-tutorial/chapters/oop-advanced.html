第十章：面向对象高级编程

难度：高级 预计学习时间：1-2 周 前置知识：面向对象编程基础

掌握了类与对象的基本概念后，本章深入 Python 面向对象的高级特性：用 __slots__ 节省内存、用 @property 优雅地封装属性、用 MixIn 组合能力、用特殊方法让类更"Pythonic"，以及枚举类与元类这些进阶工具。

__slots__ 限制实例属性

默认情况下，每个实例的属性都存在各自的 __dict__ 字典里，灵活但占用内存。当你需要创建成千上万个实例时，可以用 __slots__ 声明允许的属性名，从而禁止动态添加属性并大幅减少内存开销。

Python 
class Student:
    __slots__ = ("name", "age")   # 只允许这两个实例属性

    def __init__(self, name, age):
        self.name = name
        self.age = age

s = Student("Alice", 18)
s.name = "Bob"          # 正常
# s.score = 99         # AttributeError: 'Student' 对象没有 'score' 属性
提示

__slots__ 适合属性固定、实例极多的场景（如数据记录类）。但带 __slots__ 的类不能再动态添加属性，也略微增加了理解成本，普通业务类不必滥用。

@property 属性装饰器

直接暴露属性会破坏封装，而 get_xxx() / set_xxx() 又过于繁琐。@property 让你像访问普通属性一样读写，背后却可以嵌入校验逻辑，是 Python 推荐的封装方式。

Python 
class Celsius:
    def __init__(self, temperature=0):
        self._temperature = temperature

    @property
    def temperature(self):
        return self._temperature

    @temperature.setter
    def temperature(self, value):
        if value < -273.15:
            raise ValueError("温度不能低于绝对零度")
        self._temperature = value

c = Celsius(25)
print(c.temperature)    # 25 —— 像读属性一样，实际调用 getter
c.temperature = 30      # 像赋值一样，实际调用 setter
# c.temperature = -300  # ValueError: 温度不能低于绝对零度
前端 JS/TS 类比：getter / setter

Python 的 @property + @x.setter 与 JS/TS 类的 get / set 语法几乎一一对应：都用「像属性一样访问」的写法，背后跑自定义逻辑。

JavaScript 
class Celsius {
  constructor(temperature = 0) {
    this._temperature = temperature;
  }
  // 只读 getter / 可写 setter，等价于 Python 的 @property
  get temperature() {
    return this._temperature;
  }
  set temperature(value) {
    if (value < -273.15) throw new Error("温度不能低于绝对零度");
    this._temperature = value;
  }
}
const c = new Celsius(25);
console.log(c.temperature);  // 25
c.temperature = 30;          // 调用 setter

多重继承与 MixIn

Python 支持多重继承，但随意继承多个"类"容易混乱。常见的设计模式是 MixIn：把某个可复用能力单独写成一个类，名字通常以 Mixin 结尾，再通过多重继承"混入"到主类中，实现能力的灵活组合。

Python 
class Animal:
    def eat(self):
        return "吃东西"

class FlyMixin:
    def fly(self):
        return "我会飞"

class SwimMixin:
    def swim(self):
        return "我会游泳"

# 通过多重继承组合多种能力
class Duck(Animal, FlyMixin, SwimMixin):
    pass

d = Duck()
print(d.eat(), d.fly(), d.swim())   # 吃东西 我会飞 我会游泳
前端 JS/TS 类比：混入与接口

Python 的 MixIn 对应 JS 的「混入（mixin）」模式——把能力对象合并进原型；也对应 TS 的接口（interface）组合多个能力约束。

JavaScript 
// 用 Object.assign 组合多个能力（MixIn 模式）
const FlyMixin = {
  fly() { return "我会飞"; }
};
const SwimMixin = {
  swim() { return "我会游泳"; }
};

class Duck {}
Object.assign(Duck.prototype, FlyMixin, SwimMixin);

const d = new Duck();
console.log(d.fly(), d.swim());

// TypeScript 中接口可"组合"多个能力
// interface Flyable { fly(): void; }
// interface Swimmable { swim(): void; }
// class Duck implements Flyable, Swimmable {}

定制类：特殊方法

Python 中形如 __xxx__ 的特殊方法（dunder method）能让你的类表现得更像内建类型。实现它们，类就能支持打印、迭代、下标访问、调用、长度等直观操作。

Python 
class Vector:
    def __init__(self, x, y):
        self.x = x
        self.y = y

    def __str__(self):            # print() 时调用
        return f"Vector({self.x}, {self.y})"

    def __repr__(self):           # 调试/交互环境展示
        return f"Vector(x={self.x}, y={self.y})"

    def __add__(self, other):     # 支持 + 运算
        return Vector(self.x + other.x, self.y + other.y)

    def __getitem__(self, index): # 支持下标访问 v[0]
        return (self.x, self.y)[index]

    def __len__(self):            # 支持 len(v)
        return 2

    def __call__(self):           # 支持把实例当函数调用 v()
        return self.x ** 2 + self.y ** 2

    def __iter__(self):           # 支持 for 循环
        yield self.x
        yield self.y

v = Vector(2, 3)
print(v)              # Vector(2, 3)
print(v[0])           # 2
print(len(v))         # 2
print(v())            # 13
print(list(v))        # [2, 3]
前端 JS/TS 类比：Symbol 特殊方法

JS 用 Symbol.toStringTag 控制 Object.prototype.toString 的标签，用 Symbol.iterator 定义迭代行为——分别对应 Python 的 __str__ 与 __iter__ 等钩子。

JavaScript 
class Vector {
  constructor(x, y) { this.x = x; this.y = y; }
  // 等价于 Python 的 __str__ / __repr__
  get [Symbol.toStringTag]() { return `Vector(${this.x}, ${this.y})`; }
  // 等价于 Python 的 __iter__
  *[Symbol.iterator]() {
    yield this.x;
    yield this.y;
  }
}
const v = new Vector(2, 3);
console.log([...v]);  // [2, 3]

枚举类

用整数或字符串裸常量表示状态容易出错（例如 1 究竟代表什么？）。enum.Enum 提供有名字、可比较、不可随意赋值的枚举类型，让代码更安全、可读性更高。

Python 
from enum import Enum, auto

class Color(Enum):
    RED = 1
    GREEN = 2
    BLUE = 3

print(Color.RED)          # Color.RED
print(Color.RED.value)    # 1
print(Color(2))           # Color.GREEN —— 通过值反向查找

# auto() 自动分配递增值，省去手写
class Status(Enum):
    PENDING = auto()
    RUNNING = auto()
    DONE = auto()

print(Status.PENDING.name)  # PENDING
前端 JS/TS 类比：TypeScript 枚举

Python 的 enum.Enum 与 TypeScript 的 enum 目的一致：把一组相关常量组织成名副其实的命名成员，避免魔法数字。

JavaScript 
// JS 没有原生 enum，常用对象模拟；TS 才有原生 enum
const Color = {
  RED: "red",
  GREEN: "green",
  BLUE: "blue",
};
// TypeScript 写法（对应 Python enum.Enum）：
// enum Color { Red, Green, Blue }
// enum Status { Pending = "pending", Running = "running" }
console.log(Color.RED);  // "red"

元类简介

在 Python 中，「类也是对象」，而创建类的「类」叫元类（metaclass），默认是 type。通过自定义元类，你可以在类被创建时修改它的定义（如统一改名、自动注册）。日常开发很少需要，了解其存在即可。

Python 
# 元类控制"类的创建"，了解概念即可
class UpperAttrMetaclass(type):
    def __new__(cls, name, bases, attrs):
        uppercase_attrs = {
            key.upper(): value
            for key, value in attrs.items()
            if not key.startswith("__")
        }
        return super().__new__(cls, name, bases, uppercase_attrs)

class Config(metaclass=UpperAttrMetaclass):
    debug = True
    host = "localhost"

print(Config.DEBUG)    # True —— 属性名被元类转为大写
print(Config.HOST)     # 'localhost'

练习建议 动手实践

  1. 用 @property 做温度转换 — 定义 Temperature 类，内部存摄氏度，提供 celsius 与 fahrenheit 两个属性（华氏 = 摄氏 × 9/5 + 32），并加上越界校验。
  2. 定义颜色枚举 — 用 enum.Enum 定义一组颜色，再写一个函数根据枚举值返回对应的中文名称。
  3. 可迭代向量类 — 实现 Vector，支持 + 相加、[] 下标访问、len() 与 for 遍历，让它用起来像内建序列。
  4. __slots__ 优化 — 对比一个有 __slots__ 和一个没有的同类，分别创建十万实例，观察 __dict__ 是否存在以及内存差异。
