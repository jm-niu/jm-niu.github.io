第七章：函数式编程

难度：进阶 预计学习时间：1-2 周 前置知识：函数基础

Python 不是纯函数式语言，但它大量吸收了函数式编程的精华：函数是一等公民，可以像普通变量一样被传递、返回和组合。本章讲解高阶函数、返回函数（闭包）、lambda 表达式、装饰器与偏函数，帮你写出更简洁、更可复用的代码。

高阶函数

能接收函数作为参数、或把函数作为返回值的函数，称为高阶函数。map 把函数映射到每个元素，filter 按条件过滤，reduce（来自 functools）把序列"累积"成单个值，sorted 可用 key= 自定义排序规则。

Python 
from functools import reduce

nums = [1, 2, 3, 4, 5]

squares = list(map(lambda x: x * x, nums))
print(squares)                       # [1, 4, 9, 16, 25]

evens = list(filter(lambda x: x % 2 == 0, nums))
print(evens)                         # [2, 4]

total = reduce(lambda a, b: a + b, nums)
print(total)                         # 15

# 按字符串长度排序
words = ["pear", "apple", "banana"]
print(sorted(words, key=len))        # ['pear', 'apple', 'banana']

# 按绝对值排序
print(sorted([-3, 1, -2], key=abs))  # [1, -2, -3]
前端 JS/TS 类比：数组的 map / filter / reduce

这组 API 几乎和 JS 数组方法一一对应：map→arr.map，filter→arr.filter，reduce→arr.reduce。区别是 Python 的 map/filter 返回迭代器，需要用 list() 转成列表；JS 则直接返回新数组。

JavaScript 
const nums = [1, 2, 3, 4, 5];
const squares = nums.map(x => x * x);
const evens = nums.filter(x => x % 2 === 0);
const total = nums.reduce((a, b) => a + b, 0);

返回函数

函数可以返回另一个函数。返回的函数"记住"了外部作用域的变量，这种结构叫闭包（closure）。它常用于延迟计算和封装状态，比如下面这个计数器工厂。

Python 
def make_counter(start=0):
    count = start
    def counter():
        nonlocal count          # 声明修改外层变量
        count += 1
        return count
    return counter

c = make_counter(10)
print(c())                       # 11
print(c())                       # 12
print(c())                       # 13

# 每个实例独立持有自己的 count
d = make_counter(0)
print(d())                       # 1
print(c())                       # 14  — c 的状态未受影响
提示

闭包内部要修改外层变量时，需要 nonlocal 声明（对应全局变量用 global）。如果不加声明直接赋值，Python 会把它当成新的局部变量，导致 UnboundLocalError。

lambda 表达式

lambda 用来创建匿名函数，语法为 lambda 参数: 表达式，只能写一行、且必须有返回值。常用于作为 sorted、max、min 等函数的 key。

Python 
# 匿名函数：两数相加
add = lambda a, b: a + b
print(add(2, 3))                 # 5

students = [
    {"name": "Alice", "score": 95},
    {"name": "Bob", "score": 88},
    {"name": "Cara", "score": 92},
]

# 按 score 取最高分学生
top = max(students, key=lambda s: s["score"])
print(top)                       # {'name': 'Alice', 'score': 95}

# 按 score 升序排序
print(sorted(students, key=lambda s: s["score"]))
前端 JS/TS 类比：箭头函数

lambda a, b: a + b 与 JS 箭头函数 (a, b) => a + b 几乎等价：都是匿名、单表达式、隐式返回。但 Python 的 lambda 只能有一个表达式，JS 箭头函数花括号内可写多条语句。注意箭头函数有自己的 this 绑定语义，而 Python 无此概念。

JavaScript 
const add = (a, b) => a + b;
const top = students.reduce((m, s) => s.score > m.score ? s : m);

装饰器

装饰器（decorator）本质是一个接收函数、返回函数的高阶函数，用来在不修改原函数代码的前提下为其增加功能。本章进阶讲解：带参数的装饰器、用 functools.wraps 保留原函数元信息、以及类装饰器。

Python 
import time
import functools

# 用 wraps 保留被装饰函数的 __name__ / __doc__
def timer(func):
    @functools.wraps(func)
    def wrapper(*args, **kwargs):
        start = time.perf_counter()
        result = func(*args, **kwargs)
        print(f"{func.__name__} 耗时 {time.perf_counter() - start:.4f}s")
        return result
    return wrapper

@timer
def slow_add(n):
    total = 0
    for i in range(n):
        total += i
    return total

print(slow_add(1_000_000))
# 输出: slow_add 耗时 0.04...s

# 带参数的装饰器（再包一层）
def repeat(times):
    def decorator(func):
        @functools.wraps(func)
        def wrapper(*args, **kwargs):
            for _ in range(times):
                func(*args, **kwargs)
        return wrapper
    return decorator

# 类装饰器
class CountCalls:
    def __init__(self, func):
        self.func = func
        self.calls = 0
        functools.update_wrapper(self, func)
    def __call__(self, *args, **kwargs):
        self.calls += 1
        print(f"已调用 {self.calls} 次")
        return self.func(*args, **kwargs)
前端 JS/TS 类比：装饰器语法与高阶包装

Python 的 @timer 与 TypeScript 的实验性装饰器（@log）语法相似，都用于"包裹"目标并增强行为。但更通用的对应物是 JS 的高阶函数：const wrapped = withTimer(fn)。TS 装饰器在类/方法上声明，Python 装饰器则可读作用于任意可调用对象。

JavaScript 
// 高阶函数包装，对应 Python 的装饰器
function withTimer(fn) {
  return function (...args) {
    const t0 = performance.now();
    const r = fn(...args);
    console.log(`耗时 ${performance.now() - t0}ms`);
    return r;
  };
}
const slowAdd = withTimer((n) => { let t = 0; for (let i = 0; i < n; i++) t += i; return t; });

偏函数

functools.partial 用于"冻结"函数的部分参数，生成一个新的、参数更少的函数。最常见的用途是给有默认参数的函数（如 int 的进制转换）预设参数。

Python 
from functools import partial

# int(x, base=10) 默认按十进制解析
# 生成"专用于二进制解析"的偏函数
int2 = partial(int, base=2)
print(int2("1010"))            # 10
print(int2("1111"))            # 15

# 给 print 固定分隔符
print_pipe = partial(print, sep=" | ")
print_pipe("a", "b", "c")      # a | b | c

# 固定回调的部分参数
def greet(prefix, name):
    return f"{prefix}, {name}!"

hello = partial(greet, "你好")
print(hello("Alice"))          # 你好, Alice!
前端 JS/TS 类比：Function.prototype.bind

Python 的 partial(f, a) 与 JS 的 f.bind(null, a) 作用相同：都预设前若干个参数，返回一个新函数。JS 的 bind 还能绑定 this，而 Python 偏函数只关心位置/关键字参数，不涉及 this。

JavaScript 
const greet = (prefix, name) => `${prefix}, ${name}!`;
const hello = greet.bind(null, "你好");
console.log(hello("Alice"));     // 你好, Alice!

练习建议 动手实践

  1. 平方列表 — 用 map 加 lambda 把 [1, 2, 3, 4] 转成其平方列表 [1, 4, 9, 16]。
  2. 带缓存的装饰器 — 写一个装饰器，用字典缓存函数的入参→返回值，重复调用相同参数时直接返回缓存结果（可借助 functools.wraps），并用递归斐波那契验证速度提升。
  3. 进制转换偏函数 — 用 partial 生成 int8（八进制）和 int16（十六进制）偏函数，并解析相应字符串。
  4. 多字段排序 — 给定一组学生（含姓名、年龄、成绩），用 sorted(key=lambda ...) 先按成绩降序、成绩相同再按年龄升序排序。
