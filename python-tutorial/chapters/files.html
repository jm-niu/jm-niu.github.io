第十三章：文件与IO编程

难度：进阶 预计学习时间：1 周 前置知识：函数、数据类型

文件操作是实际编程中最常见的任务之一。无论是读取配置文件、处理数据还是写入日志，都需要掌握文件的读写技巧。本章将介绍 Python 文件操作的完整体系。

文件读写基础

Python
# 写入文件
f = open("example.txt", "w", encoding="utf-8")
f.write("Hello, Python!\n")
f.write("第二行内容\n")
f.close()  # 必须手动关闭！

# 读取文件
f = open("example.txt", "r", encoding="utf-8")
content = f.read()  # 读取全部内容
print(content)
f.close()

# 文件打开模式
# "r"  — 只读 (默认)
# "w"  — 只写 (覆盖已有内容)
# "a"  — 追加 (在末尾添加)
# "r+" — 读写
# "b"  — 二进制模式 (如 "rb", "wb")

# 逐行读取
f = open("example.txt", "r", encoding="utf-8")
for line in f:
    print(line.strip())  # strip() 去除行尾换行符
f.close()

# readlines — 读取所有行到列表
f = open("example.txt", "r", encoding="utf-8")
lines = f.readlines()
f.close()
print(lines)  # ['Hello, Python!\n', '第二行内容\n']
注意

永远指定 encoding="utf-8"。不指定编码在不同操作系统上可能产生不同的结果，导致乱码问题。

上下文管理器 (with 语句)

with 语句会在代码块执行完毕后自动关闭文件，即使发生异常也会正确关闭。这是推荐的文件操作方式。

Python
# 推荐方式 — 使用 with 语句
with open("example.txt", "w", encoding="utf-8") as f:
    f.write("使用 with 语句\n")
    f.write("自动关闭，无需手动 close\n")
# 离开 with 块后，文件已自动关闭

# 读取也一样
with open("example.txt", "r", encoding="utf-8") as f:
    for line in f:
        print(line.strip())

# 同时打开多个文件
with open("input.txt", "r") as fin, open("output.txt", "w") as fout:
    for line in fin:
        fout.write(line.upper())

# 自定义上下文管理器
class Timer:
    def __enter__(self):
        import time
        self.start = time.time()
        return self
    
    def __exit__(self, *args):
        import time
        self.elapsed = time.time() - self.start
        print(f"耗时: {self.elapsed:.3f}s")

with Timer():
    sum(range(1000000))  # 耗时: 0.023s
前端 JS/TS 类比：文件操作对比

Python 的 with 对应 Node.js 的 async/await + try/finally 模式（或使用库如 fs/promises）。Node.js 中没有内置的上下文管理器语法糖，需要手动管理资源清理。pathlib 在 JS/TS 中对应 path-browserify。

JavaScript 
// Node.js 文件读写 (类似 Python with open)
import { readFile, writeFile } from 'fs/promises';

async function readFileSafe(filePath) {
  try {
    const content = await readFile(filePath, 'utf8');
    console.log(content);
  } catch (err) {
    if (err.code === 'ENOENT') {
      console.log('文件不存在');  // 类似 FileNotFoundError
    }
  } finally {
    console.log('清理完成');  // 类似 finally
  }
}

// JSON 操作 (几乎完全一致)
const data = JSON.parse(jsonStr);     // json.loads()
const str = JSON.stringify(data);   // json.dumps()
await writeFile('data.json', JSON.stringify(data)); // json.dump()

// 路径操作 (path 模块)
import * as path from 'path';
console.log(path.basename('/a/b/c.txt'));  // c.txt (类似 Path.name)
console.log(path.extname('file.txt'));  // .txt (类似 Path.suffix)

pathlib — 现代路径操作

pathlib 是 Python 3.4+ 引入的面向对象路径操作库，比 os.path 更优雅。

Python
from pathlib import Path

# 创建路径对象
p = Path(".")                    # 当前目录
p = Path("data") / "file.txt"    # 路径拼接 (用 / 操作符)
p = Path.home()                # 用户主目录

# 路径属性
p = Path("/Users/alice/data/file.txt")
print(p.name)        # file.txt — 文件名
print(p.stem)        # file — 不含扩展名
print(p.suffix)      # .txt — 扩展名
print(p.parent)      # /Users/alice/data — 父目录
print(p.parts)       # ('/', 'Users', 'alice', 'data', 'file.txt')

# 路径操作
p = Path("data") / "file.txt"
print(p.exists())        # 是否存在
print(p.is_file())        # 是否是文件
print(p.is_dir())         # 是否是目录

# 创建目录
Path("new_dir").mkdir(exist_ok=True)

# 遍历目录
for f in Path(".").iterdir():
    print(f)

# 递归查找 — glob
for f in Path(".").rglob("*.py"):
    print(f)  # 所有 .py 文件

# pathlib 读写文件 — 一行搞定
p = Path("data.txt")
p.write_text("Hello!", encoding="utf-8")
content = p.read_text(encoding="utf-8")

JSON 处理

JSON 是现代应用中最常用的数据交换格式，Python 的 json 模块让 JSON 处理变得简单。

Python
import json

# Python 对象 → JSON 字符串
data = {
    "name": "Alice",
    "age": 25,
    "hobbies": ["reading", "coding"],
    "active": True,
    "score": None
}

json_str = json.dumps(data, indent=2, ensure_ascii=False)
print(json_str)

# JSON 字符串 → Python 对象
parsed = json.loads(json_str)
print(parsed["name"])        # Alice
print(type(parsed["hobbies"])) # <class 'list'>

# 写入 JSON 文件
with open("data.json", "w", encoding="utf-8") as f:
    json.dump(data, f, indent=2, ensure_ascii=False)

# 读取 JSON 文件
with open("data.json", "r", encoding="utf-8") as f:
    loaded = json.load(f)
    print(loaded["hobbies"])  # ['reading', 'coding']

# 类型映射关系
# Python dict  → JSON object {}
# Python list  → JSON array []
# Python str   → JSON string
# Python int/float → JSON number
# Python True/False → JSON true/false
# Python None  → JSON null

CSV 处理

Python
import csv

# 写入 CSV
rows = [
    ["姓名", "年龄", "城市"],
    ["Alice", 25, "上海"],
    ["Bob", 30, "北京"],
    ["Carol", 28, "深圳"],
]

with open("users.csv", "w", encoding="utf-8-sig", newline="") as f:
    writer = csv.writer(f)
    writer.writerows(rows)

# 读取 CSV
with open("users.csv", "r", encoding="utf-8-sig") as f:
    reader = csv.reader(f)
    for row in reader:
        print(row)

# 使用 DictReader — 更直观
with open("users.csv", "r", encoding="utf-8-sig") as f:
    reader = csv.DictReader(f)
    for row in reader:
        print(f"{row['姓名']}, {row['年龄']}岁, {row['城市']}")
提示

处理含中文的 CSV 文件时，写入用 utf-8-sig（带 BOM），读取也用 utf-8-sig，这样 Excel 打开不会乱码。同时记得加 newline="" 参数。

StringIO 与 BytesIO

有时你只是想在内存里临时读写字符串或字节，而不想真的落盘成文件。io.StringIO 提供类文件对象的字符串缓冲，io.BytesIO 则处理二进制数据，二者都支持 read/write/seek 等文件接口，常用于测试或管道处理。

Python
import io

# 在内存中读写字符串
buffer = io.StringIO()
buffer.write("Hello\n")
buffer.write("World\n")
print(buffer.getvalue())   # Hello\nWorld\n

# 回到开头读回内容
buffer.seek(0)
for line in buffer:
    print(line.strip())

# BytesIO — 处理二进制数据
bio = io.BytesIO()
bio.write(b"binary data")
print(bio.getvalue())      # b'binary data'

buffer.close()
bio.close()
前端 JS/TS 类比

JS 没有与 StringIO/BytesIO 直接对应的内置类，但可以用数组/字符串拼接近似字符串缓冲，用 Blob 或 Uint8Array 近似字节缓冲。

JavaScript
// JS 近似：用数组拼接字符串，类似 StringIO.getvalue()
const parts = [];
parts.push("Hello\n");
parts.push("World\n");
const text = parts.join("");
console.log(text);

// 二进制可用 Blob
const blob = new Blob([new Uint8Array([98, 105, 110])]);

序列化 pickle

pickle 能把任意 Python 对象（含自定义类实例）序列化到字节流，再反序列化还原。pickle.dump/pickle.load 对应写入/读取。它与 json 最大的区别是：pickle 仅限 Python、输出二进制、且绝不反序列化不可信数据（可执行任意代码）；json 才是跨语言、文本、安全的数据交换格式。

Python
import pickle

data = {"name": "Alice", "scores": [90, 85, 88]}

# 序列化到文件（二进制模式 "wb"）
with open("data.pkl", "wb") as f:
    pickle.dump(data, f)

# 反序列化
with open("data.pkl", "rb") as f:
    loaded = pickle.load(f)
print(loaded)   # {'name': 'Alice', 'scores': [90, 85, 88]}

# 与 json 对比：json 文本、跨语言、安全
import json
with open("data.json", "w", encoding="utf-8") as f:
    json.dump(data, f)
安全警告

切勿用 pickle.load 加载来源不可信的数据。pickle 在反序列化时会构造对象，攻击者可借此执行任意代码。跨进程/跨网络传输数据时请优先使用 json。

前端 JS/TS 类比

JS 没有原生的 pickle，常用 JSON.stringify/JSON.parse 做文本序列化；若只是想在内存里深拷贝（而非落盘），可用 structuredClone。

JavaScript
// JS 用 JSON 序列化（类似 pickle.dump / load）
const data = { name: "Alice", scores: [90, 85, 88] };
const str = JSON.stringify(data);    // 类似 pickle.dump
const back = JSON.parse(str);        // 类似 pickle.load

// 仅内存深拷贝（非持久化）
const clone = structuredClone(data);

os 与路径操作

os 模块提供与操作系统交互的基础能力：列出目录、创建多级目录、拼接路径等。其中 os.path 是传统的路径工具函数集合；更现代的面向对象方案是 pathlib（见上方「pathlib」小节），日常新代码推荐优先用 pathlib。

Python
import os

# 列出目录内容
print(os.listdir("."))

# 创建多级目录
os.makedirs("a/b/c", exist_ok=True)

# os.path 基础工具
path = "/Users/alice/data/file.txt"
print(os.path.basename(path))        # file.txt
print(os.path.dirname(path))         # /Users/alice/data
print(os.path.splitext(path))        # ('/Users/alice/data/file', '.txt')
print(os.path.join("a", "b", "c"))   # a/b/c (跨平台正确分隔符)

# 与 pathlib 对比（更面向对象、可读性更好）
from pathlib import Path
p = Path(path)
print(p.name, p.suffix)              # file.txt .txt
